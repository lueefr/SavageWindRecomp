# Extraction code provenance

The three Python extractors are adapted from [valentderah/totk-pc-recomp](https://github.com/valentderah/totk-pc-recomp/tree/main/tools/vendor/macnativegames), which vendors [MacNativeGames](https://github.com/ly05010419/MacNativeGames) at commit `b75be8cfa704df3701e86130c8ced268e79d6b11` (MIT).

Only `extract_exefs.py`'s game identifiers and its game-specific diagnostic are adjusted for Breath of the Wild. `extract_romfs.py` and `extract_update_romfs.py` retain their original extraction and IVFC/BKTR logic. Game data and keys are not part of this repository or release.
